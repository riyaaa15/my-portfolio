# Riya's Portfolio

A personal portfolio website built with React, Framer Motion, and CSS.

## 🚀 Live Demo
[View Portfolio](NETLIFY_LINK_HERE)

## 🛠️ Built With
- React + vite
- Framer Motion - animations
- React Scroll - Smooth scrolling
- React Icons - skill icons
- CSS - styling

## 📂 Sections
- Hero - intro with animated name
- About - bio and stats
- Skills - tech stack icons
- Projects - API projects with Github links
- Contact - email and GitHub

## 🏃 Run Locally
```bash
npm install
npm run dev
```
